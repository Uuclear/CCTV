# DB31/T 444-2022 规则包

## 来源与合规

- **标准**：上海市地方标准 DB31/T 444-2022《排水管道电视和声呐检测评估技术规程》（实施日期 2022-12-01）。
- **备案与检索**：全国标准信息公共服务平台 `https://std.samr.gov.cn/`（标准号检索）。
- **规范性引用**：该标准引用 **CJJ 181-2012**《城镇排水管道检测与评估技术规程》等；评估方法、缺陷代码与分值表在临床工程中与 CJJ 181 高度对齐。**最终以 DB31/T 444-2022 正式出版物全文为准**，发现与下列配置不一致时，只改数据文件并提高 `rules.yaml` 内 `meta.rules_version`。

## 本目录内容

| 文件 | 说明 |
|------|------|
| `rules.yaml` | 缺陷分值、默认 K/E/T、RI/MI 计算公式系数、等级阈值 |
| `README.md` | 本说明 |

## 维护流程（验收前必做）

1. 对照标准 PDF **附录 / 第 8 章** 核对 `structural_defects`、`functional_defects` 各代码 **1～4 级分值**。
2. 核对 **8.3.4 / 8.4.4** 中与 **F、G、K、E、T** 有关的公式及**前置系数**（实现见 `computation.ri.coefficient`、`computation.mi.coefficient`）；若条文为 `0.7×…` 等，在 YAML 中写入实测系数并补充单测算例。
3. 更新 `meta.rules_version`（建议语义化版本），并在 `CHANGELOG` 或提交说明中记下对照条号与页码。

## 实现说明（软件侧）

- 当前后端采用 **简化模型**：管段 **F / G** 取该管段已录缺陷在**同级别内分值的最大值**（对应 CJJ 181 中由 **Smax / Ymax** 参与比较的“最严重缺陷”一侧；完整 **S、Y** 及多缺陷间距修正需管段长度、缺陷坐标，后续可扩展）。
- **MI** 按 CJJ 181 **8.4.4** 条文说明，**不参与土质参数 T**，形式为 `coefficient × G × K × E`（见 `rules.yaml`）。
