# 产品说明 — CCTV 检测项目管理系统

## 愿景

为排水管道 **电视检测（CCTV）** 检测单位提供一套 **项目级** 管理软件：从委托立项、外业视频与看板、内业按 **DB31/T 444-2022** 录入缺陷与评估，到生成 **CC01-2 类** 检测报告与成果包，减少 Excel/Word 手工誊抄与指数计算错误。

## 目标用户

| 角色 | 诉求 |
|------|------|
| 项目经理 | 多工程进度、人员设备、成果交付期限 |
| 外业检测员 | 看板、视频挂接、现场记录 |
| 内业判读员 | 附录 D 式录入、视频定位、RI/MI 自动计算 |
| 审核员 | 缺陷与指数复核、报告签发 |
| 业主查阅（Web） | 只读查询、统计、下载成果（可选） |

## 首期范围（MVP）

- 管道 **电视检测**：**结构性 + 功能性** 缺陷与评估（规程第 7、10 章，附录 C/D/K/L）
- **Web** 协作界面 + **桌面 GUI**（本地视频与大文件）
- 报告：**Word（docxtpl）+ PDF**；统计 **xlsx** 对齐 `公共通道统计表.xlsx`
- 信息化子集：录入、审核、查询、统计、导出（规程 11.6a）

## 明确不在首期

| 能力 | 阶段 |
|------|------|
| 声呐检测（第 8 章、附录 E/F） | 二期 |
| 检查井检测与 J* 缺陷（第 9 章、表 17–18） | 二期 |
| 潜望镜 / 无人机 / 数字化电视专用流程 | 二期 |
| 缺陷 GIS 叠加、监管平台上报 | 二期 |
| 大型钢筋混凝土结构安全检测（附录 A） | 二期或独立模块 |

## 成功指标

- 单管段缺陷录入至 RI/MI 重算 **< 1 s**（本地）
- 评估算例与规程手工验算 **100% 一致**（见 `design/evaluation-engine.md` TC-EVAL-*）
- 报告导出字段与 CC01-2 范本 **人工抽查通过**（1 个完整工程）
