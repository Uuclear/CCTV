## 3. 计算公式

### 3.1 结构性：损坏状况系数 \(S\) 与缺陷参数 \(F\)

**式 (3)** — 损坏状况系数：

\[
S = \frac{100}{L} \sum_{i=1}^{n_1} P_i L_i
\]

| 符号 | 含义 |
|------|------|
| \(L\) | 被评估管道总长度 (m) |
| \(L_i\) | 第 \(i\) 处缺陷纵向长度 (m)；计量为 **个** 时，每 1 m 计 1 个，不足 1 m 按 1 个 |
| \(P_i\) | 查表 12 |
| \(n_1\) | 结构缺陷处数 |

**式 (1)(2)** — 结构性缺陷参数 \(F\)：

- 当 \(S < 40\)：\(F = 0.25 \times S\)
- 当 \(S \geqslant 40\)：\(F = 10\)

### 3.2 功能性：运行状况系数 \(Y\) 与缺陷参数 \(G\)

**式 (8)**：

\[
Y = \frac{100}{L} \sum_{i=1}^{n_2} P_i L_i
\]

（\(n_2\) 为功能缺陷处数；\(L_i\)、\(P_i\) 规则同前，\(P_i\) 查表 19；**不含 FZ**。）

**式 (6)(7)**：

- 当 \(Y < 40\)：\(G = 0.25 \times Y\)
- 当 \(Y \geqslant 40\)：\(G = 10\)

### 3.3 修复指数 RI 与养护指数 MI

**式 (4)** — 管段修复指数：

\[
RI = 0.7 \times F + 0.1 \times K + 0.05 \times E + 0.15 \times T
\]

**式 (9)** — 管段养护指数（**不含 T**）：

\[
MI = 0.8 \times G + 0.15 \times K + 0.05 \times E
\]

### 3.4 查表参数 K、E、T

## 4. 缺陷合并与 \(L_i\) 算法（实现规格）

```text
输入: 管段长度 L, 缺陷列表 defects[]
输出: S, F, Y, G, RI, MI, 等级与建议

1. 按 distance_m 排序缺陷
2. 将 distance 相差 ≤ 1.0 m 的缺陷划入同一「缺陷簇」
3. 对每个簇:
   - 若簇内仅一种代码: 一条记录, Li = max(纵向长度, 个数×1m)
   - 若多种代码: 10.1.3 权重求和 → 对每种 (code, level) 各算 Pi*Li 后相加到 sum
4. 排除 kind=functional 且 code=FZ 的项，不进入 Y
5. 计算 S, F, Y, G（分段函数）
6. 由管段属性查 K, E, T（T 仅 RI）
7. 计算 RI, MI，查表 16/21 得等级与建议字符串
```

**纵向缺陷 KS×× / JS××**：长度 > 1 m 时记录起止距离，\(L_i\) 为起止距离差（m）。

## 5. 验收算例（测试用例 ID）

### TC-EVAL-01 — 单一结构缺陷

| 项 | 值 |
|----|-----|
| L | 100 m |
| 缺陷 | PL 2 级，1 个，距离 10 m |
| P | 1.00 |
| S | 100/100 × 1.0 × 1 = **1.0** |
| F | 0.25 × 1.0 = **0.25** |
| K, E, T | 0, 0, 0 |
| **RI** | 0.7×0.25 = **0.175** → **一级** |

### TC-EVAL-02 — S 达上限

| 项 | 值 |
|----|-----|
| L | 10 m |
| 缺陷 | PL 4 级 × 4 处，每处 1 个，\(P=12\) |
| \(\sum P_i L_i\) | 4 × 12 × 1 = 48 |
| S | 100/10 × 48 = **480** → F = **10** |
| K=10, E=10, T=10 | RI = 0.7×10 + 0.1×10 + 0.05×10 + 0.15×10 = **10** → **三级** |

### TC-EVAL-03 — 功能 + FZ 不参与 MI

| 项 | 值 |
|----|-----|
| L | 50 m |
| 缺陷 A | CJ 3 级，纵向 5 m，P=1.00 → 贡献 5 |
| 缺陷 B | FZ 3 级（仅记录） | 不计入 Y |
| Y | 100/50 × 5 = **10** → G = 0.25×10 = **2.5** |
| K=3, E=3 | MI = 0.8×2.5 + 0.15×3 + 0.05×3 = **2.45** → **一级** |

### TC-EVAL-04 — 1 m 内多缺陷权重求和

| 项 | 值 |
|----|-----|
| L | 20 m |
| 缺陷 | 距离 5.0 m：PL 2 级(1个, P=1)；SL 2 级(1个, P=0.75) 同簇 |
| \(\sum P_i L_i\) | (1 + 0.75) × 1 = 1.75 |
| S | 100/20 × 1.75 = **8.75** |
| F | 0.25 × 8.75 = **2.1875** |
